# Neon Brick War

霓虹积木第三人称战争闯关（浏览器 / itch HTML5）。

原创积木风格，不含任何官方 LEGO 商标、人仔资产或 logo。

## Play

```bash
cd neon-brick-war
npm install
npm run dev
```

http://127.0.0.1:5188/ — 点击画布锁定鼠标。

| 键 | 作用 |
|----|------|
| WASD | 移动 |
| 鼠标 | 转向 |
| LMB / Space / J | 开火（轨道枪按住蓄力） |
| 1–6 / Q E / 滚轮 | 切枪 |
| R | 重生 / 重开 |
| B | 打开 itch 购买页（免费版） |
| F | 武器合成（两把枪重组出一把新的） |
| G | 机体重建（打散重组成新机体） |
| L | 切换中 / 英文 |
| `[` `]` | 音量减 / 加 |
| M | 静音 |
| Esc | 暂停（点击画布继续） |
| F3 | 碰撞体线框（调试，`?debug` 可直接开启） |

## 构建

```bash
npm run build:demo   # 免费版 → dist-demo/（前 5 关，结尾引导购买）
npm run build:full   # 完整版 → dist-full/（全战役）
npm run build        # 同 demo，输出 dist/
```

**商业化模型**：itch.io 没有客户端购买态检测 API，所以不做可被一行 localStorage 改掉的假门闸，而是**构建期双 build 拆分** —— 免费版含前 5 关，完整版由 itch 的下载密钥机制只发给购买者。本地预览用 `?unlock=all`（不在任何 UI 中暴露）。

发版前把 `VITE_PURCHASE_URL` 设成正式的 itch 页面地址。

## 已实现

- **十关战役 + 剧情**：每关有独立的关卡名、据点名、开场旁白与配色；打穿第 10 关播放四段收尾文案（"你抽掉了一块积木"）。关卡清空后 **2.4 秒自动进入下一关**，玩家不需要按键
- **中英双语**：所有面向玩家的文本走 `t([en, zh], lang)`，L 键实时切换，关卡名/据点名/武器名/Boss 名/状态行全部跟随
- **积木打散与聚拢**：角色死亡时碎成 22 块积木飞散落地（打散），玩家复活时积木从四周飞回出生点汇聚后人物重现（聚拢）。Boss 在爆炸高潮后整只炸成积木
- **机体重建**：击杀敌人积累**废料**，够数后按 G 把角色打散重组成新机体。四种机体（标准 / 侦察 / 重装 / 游走）**体型比例、血量、速度、跳跃力各不相同** —— 侦察型明显更瘦腿更长，重装型明显更宽更矮。机体是打散后重建的，不是换颜色
- **每把枪有独立的可见枪型**：六把基础枪和四把合成枪各有自己的积木枪模型（轨道枪有充能线圈、电弧枪有分叉电叉、等离子有发射盘、风暴核心是笼中光球），切枪时手上的枪真的会换
- **飞行敌人**：积木鸟，在 9m 半径、4.2m 高度环绕玩家，俯冲攻击后拉起。逼玩家抬头打地平线之上的移动目标，和地面敌人形成两种压力
- **3 个各不相同的 Boss**（设计稿 §9 完整落地）：装甲装卸机（履带底盘、正面免伤、蓄力冲锋）/ 无人机母舰（悬浮、远程射击、召唤僚机）/ 核心守卫（弱点周期性开窗、径向脉冲）。都有弱点部位、狂暴阶段新招式、分段爆炸高潮、掉落 Neon Shard
- **6 把枪**：脉冲手枪 / 散射冲锋 / 轨道步枪（蓄力穿盾）/ 榴弹发射器 / 电弧枪（链式）/ 等离子炮。各有独立数值、**曳光颜色**与**合成音色**
- **武器合成**：按 F 把手上两把枪打散重组成第三把（数据驱动的配方表）。三条配方：
  脉冲+轨道→**针刺驱动器**（轨道穿透力 + 手枪射速，穿盾）、
  散射+榴弹→**破片爆裂者**（散射弹幕 + 每颗弹丸都爆）、
  电弧+等离子→**风暴核心**（链式闪电 + 等离子规模）。
  合成会消耗两把零件枪，所以玩家要取舍；合成时角色会**打散重组成形**，复用死亡时的积木碎块系统
- **9 种道具**：医疗、护盾、急速、弹药、EMP、诱饵、扫描、双倍伤、Neon Shard
- **每关 3 个据点** A→B→C，末位据点出 Boss
- **Rapier 胶囊碰撞**：精确 AABB 穿透推出、角色可站上高处、尸体冻结不阻挡
- **画布内游戏 HUD**：无任何 DOM 覆盖层；分段血条、护盾条、动态武器槽位、蓄力条、Boss 血条（含狂暴阈值刻度）、命中反馈、受击红边、准星后坐
- **全合成音频**：零音频资源。6 把枪独立音色 + 破盾音 + Boss 登场 / 狂暴 sting + **十关各一首 BGM**（BPM/调性/音阶由关数派生，含 pad 和声层；跑在 Web Audio lookahead 步进音序器上）
- **泛光后处理** + 阴影 + 地面网格
- **付费门闸** + 双 build 拆分
- **角色步态动画**：关节骨架，双腿反相摆动、手臂反向摆、身体起伏与前倾；步频由刚体实际速度推导，不会出现脚底打滑
- **真暂停**：Esc 冻结整个模拟，HUD 有暂停遮罩
- **响应式 HUD**：布局全部由视口推导，窄屏面板纵向堆叠、文本逐级降号、横幅自动避让。已在桌面 / 平板 / 手机横屏 / 手机竖屏四种视口各跑 50 局自动化对局验证（200 局零崩溃、零卡死、零掉帧）
