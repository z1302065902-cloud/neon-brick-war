## 三、这一轮挖出的两个关键 bug（都已修）

### 1. 穿透推出把台阶当墙 → 楼梯完全不可用

`Game.clampBounds()` 是**纯水平**的最小平移量求解。它看到一个 0.22m 高的台阶，也会把玩家横向推开，所以**任何阶梯在任何关卡都爬不上去**——多层结构直接失效。

修法：只把"挡得住人"的方块当墙，脚边 0.5m 以内的高差放行，交给物理引擎去踩：

```ts
if (b.y + b.hh <= feet + 0.5) continue;   // 可迈上去的，不算墙
```

### 2. 线性阻尼吃掉了跳跃

刚体 `setLinearDamping(6)` 是为了地面防滑调的，但它同时作用在 Y 轴。8.5 的起跳冲量只换来 0.67m 高度。因为水平速度本来就由 `applyMoveVelocity()` 每帧直接设置，阻尼对水平控制没有实际作用 —— 降到 0.4 后跳跃恢复正常。

**这类"参数是为 A 场景调的，却悄悄影响了 B 场景"的问题，是这个项目里最反复出现的一类 bug。**

## 七、反复踩过的坑（重要，别重复踩）

### Rapier / 物理
- **绝不能用 `removeRigidBody` 处理尸体** —— 会让 `body` 变成悬空 WASM 句柄，之后任何 `body.translation()` 会让 Rapier **直接崩溃**（`wasm unreachable`，不是 JS 异常）。正确做法是把刚体转 Fixed + 禁用碰撞体（"冻结"）
- **`castRay` 的 `solid: true` 会在射线起点位于碰撞体内部时返回 toi=0**。做遮挡检测时必须用 `solid: false`，并用 `filterPredicate` 排除射手和目标本体，否则榴弹会永远"被自己挡住"
- **射线武器要排除目标自己的碰撞体**，否则瞄得越准越打不中（这个 bug 存在了很久才被发现）
- **飞行/悬浮敌人要用 `setTranslation` 直接控制 Y**，不要靠施加力

### 测试环境
- **测试环境没有指针锁定**，所以 `updateEnemies` 会早退、Boss 的 `update()` 不会自己跑。测 Boss 必须**手动驱动 `boss.update(dt, ctx)`**
- **`pointerLocked` 解开会触发暂停**（真暂停功能），测移动前必须 `g.input.pointerLocked = true`
- **把敌人放到竞技场外（|x| 或 |z| > 28）它会掉下去**，坐标变负会让距离判定全废
- **连续 `setTranslation` 后立刻开火，broad-phase 还没更新**，射线会打空，中间要 `await` 一个物理帧
- **不要跨波次保留敌人引用** —— 清光一波会换波并释放旧刚体，旧引用再访问就崩
- **断言要在改状态之前求值**，否则会被后续操作覆盖
- CDP 的 `resize_page` 对多标签页环境经常不生效，用 `emulate` 的 viewport 参数才可靠

### 构建
- **`node_modules` 是在 macOS 上装的，Linux 沙箱跑不了 `npm run build`**（缺 `rolldown-binding.linux-arm64-gnu.node`）。`npx tsc --noEmit` 正常
- 构建要跑到 macOS 上用终端驱动执行

## 八、运行时调试钩子

页面里 `window.__NEON_BRICK__` 就是 `Game` 实例（TS private 在运行时可访问）：

```js
g.debugState                    // map/win/ready/advancing/...
g.level.blocks                  // 关卡全部 AABB（台阶=薄而宽，高台支腿=细而方）
g.enemies / g.boss / g.pickups
g.physics.world.bodies.len()    // 泄漏检查
g.renderer.info.memory.geometries
g.hud.debugRects                // 上一帧真实绘制的矩形，专用于 HUD 布局回归
g.debris.activeCount            // 活跃积木碎块数
g.loadout.ammoSnapshot          // 各武器剩余弹药
g.audio.music / .step           // 当前 BGM 规格与步进器位置
g.tps._yaw                      // 相机偏航（只读 getter 是 yawRadians）
```
